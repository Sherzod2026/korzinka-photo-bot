# Бот сбора фото полок

Бот сидит в группе мерчендайзеров и сохраняет каждое фото с названием маркета из подписи.
Вечером (или по команде `/zip`) присылает ZIP-архив, файлы в нём названы так:

`Маркет - Мерчендайзер - ЧЧ-ММ - №.jpg`

## Правила для мерчендайзеров
- Отправлять фото в группу, в подписи — **название маркета**.
- Альбом (несколько фото сразу) — достаточно одной подписи.
- Забыли подпись — ответить (Reply) на своё фото названием маркета.

## Команды (в личном чате с ботом)
- `/stat` — сколько фото за сегодня по маркетам
- `/zip` — архив за сегодня, `/zip 2026-11-20` — за дату
- `/id` — ID чата

## Переменные окружения (Render → Environment)
| Переменная | Значение |
|---|---|
| `TELEGRAM_TOKEN` | токен от @BotFather (обязательно) |
| `GITHUB_TOKEN` | токен GitHub (classic) с правом `gist` — для хранения списка фото (нужен на бесплатном тарифе) |
| `ADMIN_CHAT_ID` | ID вашего личного чата с ботом (узнать командой `/id`) |
| `ALLOWED_CHAT_IDS` | ID группы мерчендайзеров (необязательно) |
| `SEND_HOUR` | час автоотправки архива по Ташкенту, по умолчанию `20`; `-1` — выключить |

## Запуск на Render
Web Service → Build Command: `npm install` → Start Command: `npm start`.
Список фото хранится 3 дня в секретном GitHub Gist (бот создаёт его сам), поэтому работает и на
бесплатном тарифе: сервер засыпает, но данные не теряются. После засыпания первый ответ бота
может прийти с задержкой до 1 минуты. Если в 20:00 сервер спал — архив придёт при следующем
пробуждении; в любой момент можно отправить `/zip`.
